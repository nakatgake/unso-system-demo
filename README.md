# お客様向け画面見本

index.htmlをブラウザで開くと、PC・スマホの実画面6点を見られます。画像内の操作はできません。名前・企業・報告は架空のサンプルです。
このフォルダにはAPI・DB接続・認証情報・業務データ・秘密鍵を含めません。外部のサービスへ通信するコードや解析タグもありません。
GitHub Pagesへの公開はまだ行っていません。リポジトリの非公開設定とPagesサイトの公開範囲は別です。お客様向け公開用の画像と範囲を確認してから公開します。

開発者向け：npm run build:customer-previewで、明示したファイルだけを.local-customer-preview/siteへコピーします。ZIP共有時はそのsiteフォルダの中身だけを渡します。
