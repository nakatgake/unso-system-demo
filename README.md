# お客様確認用の操作サンプル
公開用に作成した独立した静的デモ。架空データのみ。index.html、demo.css、demo.jsだけを公開する。
ホーム、個人/グループの入力、重要連絡の確認、依頼の承認/辞退/完了、掲示板、出欠回答/集計、写真付き報告/追記、社員一覧、車両枠を試せる。
入力はlocalStorageでそのブラウザ内に保持。APIへの接続、実ログイン、他端末との共有、Push、GPS、企業分離の検証は行わない。本体の実装・運用完了を意味しない。
写真はデモ保存容量のため長辺1200px/JPEG80%へ縮小する。本体の承認済み1600px/原本切替仕様とは別。
実社員・現場・顧客の情報を入力しない。写真や入力は「試した内容を最初に戻す」で消せる。
