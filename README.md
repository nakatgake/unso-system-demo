# お客様確認用の操作サンプル

公開URL: https://nakatgake.github.io/unso-system-demo/

PC・スマートフォン対応の独立した静的サンプルです。架空データのみを使用します。
ホーム、個人・グループチャット、会話内検索、重要連絡の確認、業務依頼の引受・辞退・完了と履歴、掲示板、出欠回答・回答履歴・集計CSV、写真付き報告・返信・追記、社員一覧、車両管理の画面枠を試せます。

入力と写真はIndexedDBでそのブラウザ内に保存します。通常の写真は長辺1600px・JPEG品質80%を目安に圧縮し、原本へ切替可能です。1枚20MB・10枚まで。架空の写真を追加するボタンでも試せます。実際の社員情報や現場写真は入力しないでください。

API接続、実ログイン、社員への送信、Push、GPS、他端末との共有、企業分離の検証は行いません。集計保存はCSVです。本体システムの実装・運用完了を意味しません。ブラウザの保存が利用できない場合は画面上に案内します。

ローカル確認: リポジトリのルートで `node scripts/serve-customer-demo.mjs` を実行し http://127.0.0.1:5186/ を開きます。
公開対象は index.html、demo.css、demo.js、README.md、.nojekyll の5ファイルに限定します。

## 2026-11-27 チャットの写真添付

ユーザー指示により公開サンプルのチャットへ撮影・写真選択、送信前プレビュー/取り消し、文章と写真の同時送信/写真のみ送信を追加。通常は長辺1600px/JPEG80%へ圧縮し原本切替可、20MB/10枚まで。会話ごとに編集中の文章・写真を保持し誤送信を防ぐ。保存先は既存IndexedDBのみで外部送信なし。本体アプリは今回未変更。実機のカメラ起動・許可とソフトキーボードは未検証。

## 2026-11-27 重要連絡と個人の重要保存

ユーザー指示により公開サンプルのホーム最上部（挨拶直後）へ重要連絡欄を移動。未確認一覧と、確認済み/自分の送信を含む全件一覧を用意。チャット作成時に「重要連絡として送る」を選択可能。自分の送信は自分宛の未確認件数へ加算せず、自分には確認ボタンを出さない。発言ごとの「重要保存」は端末内の自分用ブックマークとして重要連絡/グループ固定と区別し、ホームと会話の操作から見返す。元の発言へ移動可能。既存データを削除せず任意フィールドで保存。本体API/権限や相手の確認状況・再通知・実送信は今回の静的サンプル対象外。
